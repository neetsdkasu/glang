# glang

雑にプログラミングするやつ.  


## 言語仕様（雑）


### 型

| 種別 | キーワード | 補足説明 |
|-----|-----------|----------|
| 真偽 | `boolean` | |
| 整数 | `integer` | 符号付32bit、内部表現は実行環境に依存（おそらく2の補数） |
| 浮動小数点数 |`float` | 64bit、内部表現は実行環境に依存 |
| 文字列 | `string` | 文字コードは実行環境に依存 |


### 使う文字種

| 文字種       | 主な用途     |
|-------------|--------------|
| 半角スペース | 空白文字      |
| 水平タブ     | 空白文字     |
| 改行         |行の区切り    |
| 半角アルファベット（大文字小文字の区別なし）  | キーワード、変数名、関数名   |
| 半角数字           | 変数名や関数名の一部、数値   |
| 半角ピリオド（`.`） | 小数点、メソッド風呼び出し  |
| 半角カンマ（`,`）   | パラメータや引数の区切り  |
| 半角シングルクオート（`'`） | コメントの開始 |
| 半角ダブルクオート（`"`） | 文字列を囲む |
| 半角プラス（`+`） | 二項演算子：数値の足し算、単項演算子：正数、代入文の一部、二項演算子：文字列の連結 |
| 半角マイナス（`-`） | 二項演算子：引き算、単項演算子：負数、代入文の一部 |
| 半角アスタリスク（`*`） | 二項演算子：掛け算、代入文の一部 |
| 半角スラッシュ（`/`） |  二項演算子：浮動小数点数用割り算、代入文の一部 |
| 半角円記号 あるいは 半角バックスラッシュ（`\`） |  二項演算子：整数用割り算、代入文の一部 |
| 半角パーセント（`%`） |  二項演算子：整数用余り算、代入文の一部 |
| 半角等号（`=`） |  代入文の一部、比較の二項演算子の一部 |
| 半角チルダ（`~`） |  単項演算子：ビット反転 |
| 半角感嘆符（`!`） | 比較の二項演算子の不一致判定の一部、単項演算子：論理演算の否定 |
| 半角アンサパンド（`&`） | 二項演算子：ビット論理積、二項演算子の論理積の一部、代入文の一部 |
| 半角パイプライン（`\|`） | 二項演算子：ビット論理和、二項演算子の論理和の一部、代入文の一部 |
| 半角キャレット（`^`） | 二項演算子：ビット排他的論理和、代入文の一部 |
| 半角小なり（`<`） | 二項演算子のビット演算の左シフトの一部、比較の二項演算子の一部、代入文の一部 |
| 半角大なり（`>`）| 二項演算子のビット演算の右シフトの一部、比較の二項演算子の一部、代入文の一部 |
| 半角丸括弧（ `(`,`)`） | 演算順序の指定、引数の指定、配列の次元数の指定 |


### 行

 - コメント行
 - インライン命令
 - ブロック命令
 - ブロック区切り
 - 代入文

#### コメント行

記号`'`から行末までがコメントになる.
行頭から記号`'`までに空白文字があってもよい.

```basic
' コメント行

    ' コメント行
```

#### インライン命令

| 命令キーワード | 概要          |
|---------------|--------------|
| `dim`    | 配列定義           |
| `let`    | 変数定義           |
| `call`   | 関数呼び出し       |
| `return` | ユーザ関数脱出、ユーザ関数終端での戻り値を指定 |
| `break`       | ループブロック脱出 |
| `continue`    | ループ反復 |
| `randomize`   | 乱数の初期化 |
| `print`       | デバッグ用文字出力  |
| `setcolor`    | 描画の色を指定 |
| `setfontsize` | 描画の文字サイズを指定 |
| `drawline` | オフバッファに線を描画 |
| `drawrect` | オフバッファに矩形を描画 |
| `drawarc` | オフバッファに円弧を描画 |
| `drawtext` | オフバッファにテキストを描画 |
| `fillrect` | オフバッファに塗りつぶされた矩形を描画 |
| `fillarc` | オフバッファに塗りつぶされた円弧を描画 |
| `flush` | オフバッファの描画内容を維持したままオフバッファの描画内容を表示画面にコピー |
| `transfer` | オフバッファの描画内容を表示画面に反映し、オフバッファの描画内容は削除する |
| `getpointerevent` | 表示画面へのクリック・タッチのイベントの状態を取得する |


#### ブロック命令

| 命令キーワード | 概要          |
|---------------|--------------|
| `sub`    | 戻り値のないユーザ関数を定義  |
| `func`   | 戻り値のあるユーザ関数を定義  |
| `if`     | 条件分岐の開始 |
| `for`    | 単調変化数値条件ループ |
| `do`     | 任意条件付きループ |

#### ブロック終端

| キーワード | 概要          |
|-----------|--------------|
| `else`     | 命令キーワード`if`の条件が不一致のときの分岐先のブロックを定義する |
| `end`      | ブロック命令キーワードと組み合わせてブロックの終端を定義する |


```basic
for let x = 8 to 12
    if x == 10 then
        print "x is 10"
    else
        print "x is not 10"
    end if
end for
```

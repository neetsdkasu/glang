# glang

ブラウザ上で独自プログラミング言語で雑にプログラミングするやつ.  
キーワードや構文の多くはBASIC言語系統を参考にしている.
ブラウザのCanvasに簡易なお絵描きする程度のことしかできない.


## 言語仕様（雑）


### 実行環境

glangはブラウザ上で実行されることが想定されており、コード実行の処理の大半をブラウザのJavascriptに丸投げするので処理結果がブラウザに実装されているJavascriptエンジンの仕様に依存する.


### エントリポイント

キーワード`sub`で定義された`main`という名前のユーザ関数がプログラムのエントリポイント（開始点）となる.


### 型

| 種別 | キーワード | 補足説明 |
|-----|-----------|----------|
| 真偽値 | `boolean` | 値は真の`true`と偽の`false`の2種類のみ |

### 単項演算子

単項演算子の演算は二項演算子の演算より優先される.


| 演算子 | 対象 | 概要 |
|-------|------|------|
| `+` | 整数、浮動小数点数 | この単項演算子は値を変化させることもなくソースコード上も実行時も何も意味をなさない |
| `-` | 整数、浮動小数点数 | 値の正負を反転させる |
| `~` | 整数 | すべてのビットの`0`と`1`を`1`と`0`に変える |
| `!` | 真偽値 | 真偽値の値が`true`なら`false`に、`false`なら`true`に変える |


### 二項演算子

式に複数の演算子がある場合は優先度が高い順に演算される.
左結合（優先度が同じなら先に出現した演算子の演算が優先される）.
式に丸括弧が存在する場合は丸括弧で囲まれた式の演算がその丸括弧の外側の演算子の演算より優先される.


| 演算子 | 優先度 | 対象 | 概要 |
|-------|----------|------|------|
| `+` | 90 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は和の値を計算する、文字列同士の場合は連結する |
| `-` | 90 | 整数、浮動小数点数 | 整数同士または浮動小数点数同士の差の値を計算する |
| `*` | 100 | 整数、浮動小数点数 | 整数同士または浮動小数点数同士の積の値を計算する |
| `/` | 100 | 浮動小数点数 | 右の値に対する左の値の比を計算する |
| `\` | 100 | 整数 | 商の値を計算する |
| `%` | 100 | 整数 | 余りの値を計算する |
| `<<` | 80 | 整数 | 符号ビット以外のビットで左シフト演算をする（符号ビットはシフトされず保存される）、シフトサイズは右の値と`31`とのビット論理積された値が使用される |
| `>>` | 80 | 整数 | 符号ビット以外のビットで右シフト演算をする（空いた上位ビットは符号ビットのコピーで埋められる）、シフトサイズは右の値と`31`とのビット論理積された値が使用される |
| `<<<` | 80 | 整数 | 符号ビットがないものとして左シフト演算をする（符号ビットはシフトで追い出される）、シフトサイズは右の値と`31`とのビット論理積された値が使用される |
| `>>>` | 80 | 整数 | 符号ビットがないものとして右シフト演算をする（符号ビットを含め空いた上位ビットは`0`で埋められる）、シフトサイズは右の値と`31`とのビット論理積された値が使用される |
| `&` | 70 | 整数、真偽値 | 整数同士ならビット論理積を計算する、真偽値同士は両方が`true`なら`true`にそれ以外なら`false`になる |
| `\|` | 60 |  整数、真偽値 | 整数同士ならビット論理和を計算する、真偽値同士は両方が`false`なら`false`にそれ以外なら`true`になる |
| `^` | 50 | 整数 | ビット単位の排他的論理和を計算する |
| `==` | 40 | すべての型 | 同じ型同士の値が一致するかを判定する（判定基準は実行環境に丸投げするので実行環境に依存する） |
| `!=` | 40 | すべての型 | 同じ型同士の値が不一致であるかを判定する（判定基準は実行環境に丸投げするので実行環境に依存する） |
| `<` | 40 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は左の値が右の値より小さいなら`true`にそうでないなら`false`になる、文字列同士の場合は左の文字列が辞書順で先にくるなら`true`にそうでないなら`false`になる（辞書順の定義は実行環境に依存する） |
| `<=` | 40 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は左の値が右の値と同じまたは小さいなら`true`にそうでないなら`false`になる、文字列同士の場合は左の文字列が辞書順で同じまたは先にくるなら`true`にそうでないなら`false`になる（辞書順の定義は実行環境に依存する） |
| `>` | 40 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は左の値が右の値より大きいなら`true`にそうでないなら`false`になる、文字列同士の場合は左の文字列が辞書順で後にくるなら`true`にそうでないなら`false`になる（辞書順の定義は実行環境に依存する） |
| `>=` | 40 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は左の値が右の値と同じまたは大きいなら`true`にそうでないなら`false`になる、文字列同士の場合は左の文字列が辞書順で同じまたは後にくるなら`true`にそうでないなら`false`になる（辞書順の定義は実行環境に依存する） |
| `&&` | 30 | 真偽値 | 左の値が`false`なら右の値を計算せずに`false`になる、そうでないなら右の値になる |
| `\|\|` | 20 |　真偽値 | 左の値が`true`なら右の値を計算せずに`true`になる、そうでないなら右の値になる |

## リファレンス（雑）

表記例（命令）
```
keyword param1 , param2 [ , param3 ]
```
表記例（戻り値のある関数）
```
func name( arg1 as type1 , arg2 as type2 , arg3 as type3 ) as type4
```
表記例（戻り値のない関数）
```
sub name( arg1 as type1 , arg2 as type2 , arg3 as type3 )
```

| 表記例 | 説明             |
|-------|------------------|
| `keyword` |  命令キーワード. |
| `param1`, `param2`, `param3` | 命令に与えるパラメータ. |
| 角括弧 `[ ]` | 省略可能なパラメータを囲む. |
| `name` | ここでは関数名を表す. |
| 丸括弧 `( )` | 関数の引数のリストを囲む. 配列の次元数指定にも使用される. |
| `arg1`, `arg2`, `arg3` | 関数に渡す引数の仮名（仮引数名に相当）. |
| `type1`, `type2`, `type3` | 引数の型. |
| `type4` | 関数の戻り値の型. |
| `func`, `sub` | 関数の定義であることを表すキーワード. |
| カンマ `,` | パラメータや引数の区切り. |
| `as` | ここでは関数定義の型指定のフォーマットにのっとっただけのキーワード. |


### インライン命令（アルファベット昇順）

#### await

```
await time
```
前回の`await`の呼び出し時点の時刻から`time`ミリ秒経過していないなら`time`ミリ秒経つまで実行を足止めする.  
`time`は`1`以上`1000`以下の整数リテラルで指定する必要がある.  
初回の`await`呼び出し時はプログラムの実行開始時の時刻からの経過時間が`time`ミリ秒経過していないなら`time`ミリ秒経つまで実行を足止めする.


#### break
```
break
```
`for`ループのブロックから脱出しブロック終端の`end for`の次の行から実行を再開する.  
あるいは、
`do while`ループのブロックから脱出しブロック終端の`end do`の次の行から実行を再開する.  
ループのブロックがネストしている場合`break`呼び出しの位置までの最も深い位置にあるループブロック1つから脱出する（複数のループブロックすべてから一度に脱出することはない）.  

```
' 例（ break は for let j のブロックから脱出する ）
let x = 1
do while x <= 10
    x += 1
    for let i = 1 to 10
        for let j = 1 to 10
            if i + j == 2 * x then
                break
            end if
            for let k = 1 to 10
                print x, i, j, k
            end for
        end for
    end for
end do
```

### call

例えば引数が3個の関数の場合
```
call name( arg1 , arg2 , arg3 )
```
例えば引数が1個の関数の場合
```
call name( arg1 )
```
例えば引数が0個の関数の場合
```
call name()
```

関数名`name`の標準関数もしくはユーザ関数を呼び出す（実行する）.  
引数は関数の定義によって指定された数だけ指定された型の式で指定する.  
呼び出した関数に戻り値がある場合はその値は無視（破棄）され使用されない. 



### continue
```
continue
```
`for`ループのブロックの`continue`呼び出しからブロック終端の`end for`までの処理を省きループ先頭に戻りループカウンタを更新しループ継続の判定処理をする.  
あるいは、
`do while`ループのブロックの`continue`呼び出しからブロック終端の`end do`までの処理を省きループ先頭に戻りループ継続の判定処理をする.  
ループのブロックがネストしている場合`continue`呼び出しの位置までの最も深い位置にあるループブロックに対して処理される.  
```
' 例（ continue は for let j の先頭に戻りループカウンタを更新しループ継続の判定処理を行う ）
let x = 1
do while x <= 10
    x += 1
    for let i = 1 to 10
        for let j = 1 to 10
            if i + j == 2 * x then
                continue
            end if
            for let k = 1 to 10
                print x, i, j, k
            end for
        end for
    end for
end do
```


### dim

1次元配列の場合
```
dim name( size1 ) as type
```
2次元配列の場合
```
dim name( size1 , size2 ) as type
```
3次元配列の場合
```
dim name( size1 , size2 , size3 ) as type
```
1次元配列または2次元配列または3次元配列を定義する.

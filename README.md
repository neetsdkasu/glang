# glang

雑にプログラミングするやつ.  


## 言語仕様（雑）


### エントリポイント

キーワード`sub`で定義された`main`という名前のユーザ関数がプログラムのエントリポイント（開始点）となる.


### 型

| 種別 | キーワード | 補足説明 |
|-----|-----------|----------|
| 真偽値 | `boolean` | 値は真の`true`と偽の`false`の2種類のみ |
| 整数 | `integer` | 符号付32bit、内部表現は実行環境に依存（おそらく2の補数） |
| 浮動小数点数 |`float` | 64bit、内部表現は実行環境に依存 |
| 文字列 | `string` | 文字コードは実行環境に依存 |


### 使う文字種

| 文字種       | 主な用途     |
|-------------|--------------|
| 半角スペース | 空白文字      |
| 水平タブ     | 空白文字     |
| 改行         |行の区切り    |
| 半角アルファベット（大文字小文字の区別なし）  | キーワード、変数名、関数名   |
| 半角数字           | 変数名や関数名の一部、数値   |
| 半角ピリオド（`.`） | 小数点、メソッド風呼び出し  |
| 半角カンマ（`,`）   | パラメータや引数の区切り  |
| 半角シングルクオート（`'`） | コメントの開始 |
| 半角ダブルクオート（`"`） | 文字列を囲む |
| 半角プラス（`+`） | 二項演算子：数値の足し算、単項演算子：正数、代入文の一部、二項演算子：文字列の連結 |
| 半角マイナス（`-`） | 二項演算子：引き算、単項演算子：負数、代入文の一部 |
| 半角アスタリスク（`*`） | 二項演算子：掛け算、代入文の一部 |
| 半角スラッシュ（`/`） |  二項演算子：浮動小数点数用割り算、代入文の一部 |
| 半角円記号 あるいは 半角バックスラッシュ（`\`） |  二項演算子：整数用割り算、代入文の一部 |
| 半角パーセント（`%`） |  二項演算子：整数用余り算、代入文の一部 |
| 半角等号（`=`） |  代入文の一部、比較の二項演算子の一部 |
| 半角チルダ（`~`） |  単項演算子：ビット反転 |
| 半角感嘆符（`!`） | 比較の二項演算子の不一致判定の一部、単項演算子：論理演算の否定 |
| 半角アンサパンド（`&`） | 二項演算子：ビット論理積、二項演算子の論理積の一部、代入文の一部 |
| 半角パイプライン（`\|`） | 二項演算子：ビット論理和、二項演算子の論理和の一部、代入文の一部 |
| 半角キャレット（`^`） | 二項演算子：ビット排他的論理和、代入文の一部 |
| 半角小なり（`<`） | 二項演算子のビット演算の左シフトの一部、比較の二項演算子の一部、代入文の一部 |
| 半角大なり（`>`）| 二項演算子のビット演算の右シフトの一部、比較の二項演算子の一部、代入文の一部 |
| 半角丸括弧（ `(`,`)`） | 演算順序の指定、引数の指定、配列の次元数の指定 |


### 単項演算子

単項演算子の演算は二項演算子の演算より優先される.


| 演算子 | 対象 | 概要 |
|-------|------|------|
| `+` | 整数、浮動小数点数 | この単項演算子は値を変化させることもなくソースコード上も実行時も何も意味をなさない |
| `-` | 整数、浮動小数点数 | 値の正負を反転させる |
| `~` | 整数 | すべてのビットの`0`と`1`を`1`と`0`に変える |
| `!` | 真偽値 | 真偽値の値が`true`なら`false`に、`false`なら`true`に変える |


### 二項演算子

式に複数の演算子がある場合は優先度が高い順に演算される.
左結合（優先度が同じなら先に出現した演算子の演算が優先される）.
式に丸括弧が存在する場合は丸括弧で囲まれた式の演算がその丸括弧の外側の演算子の演算より優先される.


| 演算子 | 優先度 | 対象 | 概要 |
|-------|----------|------|------|
| `+` | 90 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は和の値を計算する、文字列同士の場合は連結する |
| `-` | 90 | 整数、浮動小数点数 | 整数同士または浮動小数点数同士の差の値を計算する |
| `*` | 100 | 整数、浮動小数点数 | 整数同士または浮動小数点数同士の積の値を計算する |
| `/` | 100 | 浮動小数点数 | 右の値に対する左の値の比を計算する |
| `\` | 100 | 整数 | 商の値を計算する |
| `%` | 100 | 整数 | 余りの値を計算する |
| `<<` | 80 | 整数 | 符号ビット以外のビットで左シフト演算をする（符号ビットはシフトされず保存される）、シフトサイズは右の値と`31`とのビット論理積された値が使用される |
| `>>` | 80 | 整数 | 符号ビット以外のビットで右シフト演算をする（空いた上位ビットは符号ビットのコピーで埋められる）、シフトサイズは右の値と`31`とのビット論理積された値が使用される |
| `<<<` | 80 | 整数 | 符号ビットがないものとして左シフト演算をする（符号ビットはシフトで追い出される）、シフトサイズは右の値と`31`とのビット論理積された値が使用される |
| `>>>` | 80 | 整数 | 符号ビットがないものとして右シフト演算をする（符号ビットを含め空いた上位ビットは`0`で埋められる）、シフトサイズは右の値と`31`とのビット論理積された値が使用される |
| `&` | 70 | 整数、真偽値 | 整数同士ならビット論理積を計算する、真偽値同士は両方が`true`なら`true`にそれ以外なら`false`になる |
| `\|` | 60 |  整数、真偽値 | 整数同士ならビット論理和を計算する、真偽値同士は両方が`false`なら`false`にそれ以外なら`true`になる |
| `^` | 50 | 整数 | ビット単位の排他的論理和を計算する |
| `==` | 40 | すべての型 | 同じ型同士の値が一致するかを判定する（判定基準は実行環境に丸投げするので実行環境に依存する） |
| `!=` | 40 | すべての型 | 同じ型同士の値が不一致であるかを判定する（判定基準は実行環境に丸投げするので実行環境に依存する） |
| `<` | 40 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は左の値が右の値より小さいなら`true`にそうでないなら`false`になる、文字列同士の場合は左の文字列が辞書順で先にくるなら`true`にそうでないなら`false`になる（辞書順の定義は実行環境に依存する） |
| `<=` | 40 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は左の値が右の値と同じまたは小さいなら`true`にそうでないなら`false`になる、文字列同士の場合は左の文字列が辞書順で同じまたは先にくるなら`true`にそうでないなら`false`になる（辞書順の定義は実行環境に依存する） |
| `>` | 40 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は左の値が右の値より大きいなら`true`にそうでないなら`false`になる、文字列同士の場合は左の文字列が辞書順で後にくるなら`true`にそうでないなら`false`になる（辞書順の定義は実行環境に依存する） |
| `>=` | 40 | 整数、浮動小数点数、文字列 | 整数同士または浮動小数点数同士の場合は左の値が右の値と同じまたは大きいなら`true`にそうでないなら`false`になる、文字列同士の場合は左の文字列が辞書順で同じまたは後にくるなら`true`にそうでないなら`false`になる（辞書順の定義は実行環境に依存する） |
| `&&` | 30 | 真偽値 | 左の値が`false`なら右の値を計算せずに`false`になる、そうでないなら右の値になる |
| `\|\|` | 20 |　真偽値 | 左の値が`true`なら右の値を計算せずに`true`になる、そうでないなら右の値になる |


### 行

 - コメント行
 - インライン命令
 - ブロック命令

#### コメント行

記号`'`から行末までがコメントになる.
行頭から記号`'`までに空白文字があってもよい.

```basic
' コメント行

    ' コメント行
```

#### ブロック命令

| 命令キーワード | 概要          |
|---------------|--------------|
| `sub`    | 戻り値のないユーザ関数を定義  |
| `func`   | 戻り値のあるユーザ関数を定義  |
| `if`     | 条件分岐の開始 |
| `for`    | 単調変化数値条件ループ |
| `do`     | 任意条件付きループ |

#### ブロック区切り

| キーワード | 概要          |
|-----------|--------------|
| `else`     | 命令キーワード`if`の条件が不一致のときの分岐先のブロックを定義する |
| `end`      | ブロック命令キーワードと組み合わせてブロックの終端を定義する |


```basic
for let x = 8 to 12
    if x == 10 then
        print "x is 10"
    else
        print "x is not 10"
    end if
end for
```

#### 代入文

変数や配列要素への値の代入や格納されている値に対する演算を行う.
型は一致させる必要がある.

|-----------|-----------------|
| `=`       | 値の代入         |
| `+=`      | 格納されている値との二項演算子`+`の計算結果を代入 |
| `-=`      | 格納されている値との二項演算子`-`の計算結果を代入 |
| `*=`      | 格納されている値との二項演算子`*`の計算結果を代入 |
| `/=`      | 格納されている値との二項演算子`/`の計算結果を代入 |
| `\=`      | 格納されている値との二項演算子`\`の計算結果を代入 |
| `%=`      | 格納されている値との二項演算子`%`の計算結果を代入 |
| `>>=`     | 格納されている値との二項演算子`>>`の計算結果を代入 |
| `<<=`     | 格納されている値との二項演算子`<<`の計算結果を代入 |
| `>>>=`    | 格納されている値との二項演算子`>>>`の計算結果を代入 |
| `<<<=`    | 格納されている値との二項演算子`<<<`の計算結果を代入 |
| `&=`      | 格納されている値との二項演算子`&`の計算結果を代入 |
| `\|=`     | 格納されている値との二項演算子`\|`の計算結果を代入 |
| `^=`      | 格納されている値との二項演算子`^`の計算結果を代入 |
